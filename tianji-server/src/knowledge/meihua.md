# 梅花易数 知识库

> 领域：东方命理 ｜ 系统：meihua

## 体系概述

梅花易数又称「梅花心易」，相传为北宋邵雍（邵康节）所著，是中国易占体系中极其灵活的一支。它依据「万物类象」「万物皆数」原理，随时随地都可以用时间、数字、声音、方位、外应起卦，综合《周易》卦爻辞、体用、互变、五行生克判断吉凶。其开山案例「观梅占」源于邵雍观梅时见二雀争枝坠地，起卦断出次日有女子折花受惊跌伤之事，因应验精准而得名。与六爻的固定铜钱成卦不同，梅花易数强调「随机取象」「不动不占，不因事不占」，以先天八卦数（乾一兑二离三震四巽五坎六艮七坤八）配后天八卦方位（坎北离南震东兑西乾西北坤西南巽东南艮东北），起卦简便、断卦灵活，被称为「运用之妙，存乎一心」。

## 核心概念与术语

- 先天八卦数：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八，用于取数定卦。
- 后天八卦方位：坎北、离南、震东、兑西、乾西北、坤西南、巽东南、艮东北。
- 地支序数：子1丑2寅3卯4辰5巳6午7未8申9酉10戌11亥12，用于时间起卦。
- 本卦（主卦）：起卦所得之卦，代表事情当前状态。
- 互卦：由本卦中间四爻（二三四爻为下互、三四五爻为上互）重新组合而成，代表事情中间过程与隐藏结构。
- 变卦：本卦动爻阴阳互换后所得之卦，代表事情发展结果与趋势。
- 体卦：通常为无动爻的卦，代表问卦人自身、本位与承载能力。
- 用卦：通常为动爻所在的卦，代表所测之事、外部对象与互动焦点。
- 体用生克：体用比和主吉；用生体主吉、事顺；体生用主耗泄、费力；体克用主事可成但费劲；用克体主凶、事受阻。
- 外应：起卦或断卦过程中突然出现的自然现象，作为辅助断事的征兆；必须突然、自然发生，不可刻意制造。
- 三要：耳（听声）、目（观色）、心（起念）三种取象渠道。
- 十应：天时、地理、人品、时节、外物、文字、声音、颜色、出行、动作十类应验参考。
- 万物类象：八卦对应的人、物、身体、颜色、方位等象征体系，如乾为父老男人、巽为股、离为目火、兑为少女口舌等。

## 起卦方法

- 时间起卦（年月日时起卦）：上卦=（年支数+农历月数+农历日数）÷8 取余；下卦=（年支数+月数+日数+时支数）÷8 取余；动爻=（总数）÷6 取余。整除时分别取 8 或 6。先换为农历，年取年支序数、时取时支序数。
- 数字起卦：随意报两个数，第一个数÷8 余数为上卦，第二个数÷8 余数为下卦，两数之和÷6 余数为动爻。凡所见数字（车牌、电话、页码、扑克等）均可起卦。
- 单数起卦：报一个数，除以 8 取上卦，加时辰数作内卦（下卦），总数÷6 取动爻。
- 方位起卦（端法后天起卦）：以人或物的万物类象属性为上卦，以其所在后天八卦方位为下卦，上下卦数加时数÷6 取动爻。如老人（乾）往巽方，得天风姤。
- 声音起卦：数声数起上卦，加时数配下卦；有间隔的取间隔前后分别作上下卦。
- 测字起卦：字少按笔画数分上下卦，字多按字数分；单字可拆上下/左右/内外两部分各数笔画。
- 外应起卦：起卦时突现的声音、动作、颜色、场景直接对应八卦取卦。
- 起卦原则：不动不占、不因事不占；一事一卦，同一问题反复起卦易致解释混乱；外应须「怪」（异常突现）才可取。

## 解读范式

- 断卦顺序：确定体用 → 五行生克分析 → 看互卦（过程）→ 看变卦（结果趋势）→ 结合四值（年月日时旺衰）→ 万物类象取象 → 卦爻辞佐证 → 外应验证。
- 体用判断：动爻所在的卦为用，无动爻的卦为体。以体为我、用为事，体用生克定吉凶大势，变卦定结果倾向。
- 五行生克结合时令：体卦克用卦主我占优势，但对方旺相时可能反制；结合年支、月支、日支、时支四值判断卦气旺衰修正结论。
- 类象落地：把八卦象征对应到现实场景，如兑为少女口舌、乾为长者主管、巽为草木项目文书。如「泽火革变泽山咸」可象职场上年轻女性同事因系统更新受阻致项目出错。
- 互卦看中间过程、变卦看结果：「观梅占」中互卦见巽（股）乾（金克木）推伤股，变卦艮土生兑金知不致凶危。
- 卦爻辞辅助：爻辞吉凶与卦理结合互证，如天风姤九四「包无鱼，起凶」与金克体木的卦理同断。

## 应期推断

- 以卦数定应期：成卦之数（起卦数字之和）作为应期基数。
- 以动静定迟速：行则数减半、事应速；坐则数乘二（或按原数）、事应迟；立则半迟半速取原数。如「老人有忧色占」成卦十数、行人取半为五日应验。
- 用生体之应：以生体之卦对应的五行日、月为应期，如坎水生体则应在壬癸亥子之日。
- 克体之应：以克体之卦五行之日、月为凶期，如乾金克体则应在庚申辛酉之日。
- 外应定应期：结合外应出现的时间、场景特征判断。

## 经典文献
