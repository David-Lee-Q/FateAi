# 风水 知识库

> 领域：东方命理 ｜ 系统：fengshui

## 体系概述

风水古称堪舆，「堪，天道也；舆，地道也」，是以天文历法配合地理环境选择与处理人居环境（阳宅）和祖先陵墓（阴宅）的学问。其核心是「生气」观：郭璞《葬书》云「葬者，乘生气也，气乘风则散，界水则止，古人聚之使不散，行之使有止，故谓之风水。风水之法，得水为上，藏风次之」。风水分为两大宗派：以杨筠松为代表的峦头派（形势派、江西派）注重山形水态，以龙、穴、砂、水、向「地理五诀」为勘察依据；以宋代集大成的理气派（福建派）依据阴阳、河图洛书、先后天八卦、五行九星推断方位吉凶，流派有八宅派、三元派、三合派、八卦派等。后人共识「峦头为体，理气为用」「形法无理气不灵，理气无形法不准」，须形理结合方为真学。

## 核心概念与术语

- 地理五诀（龙穴砂水向）：寻龙、点穴、察砂、观水、立向，风水勘察选址的五大要素。
- 龙：起伏山脉即龙脉，山脉由高到低如龙飞凤舞。寻龙要先观太祖山、少祖山、父母山，看剥换、开帐、过峡、入首。「山主人丁水主财」。
- 穴：龙脉真气融聚的结穴之所，阳宅基地中心点或阴宅金井。「三年寻龙，十年点穴」。
- 砂：龙旁环卫穴场的小山丘，包括朝峰、案山、贵人、青龙白虎等，作用在护龙、护穴、关水。砂以尖圆方正、秀丽光彩、环抱有情为吉，破碎反逆为凶；圆肥主富、尖秀主贵。
- 水：明堂之水。来水处为天门要开（天门不开不来财），去水处为地户要闭（地户不闭不聚财）。「明堂容万马，水口不通舟」。眠弓水、金城御带水为吉水，「之玄」状水流最贵。杨公「杨水一勺可救贫」。
- 向：阳宅阴宅的朝向，应根据来龙定穴、消砂纳水而立向。「千里江山一向间，向字要当先」，最佳向只有一个。
- 藏风得水：穴场四周形局紧密卫护穴庭、不受外风侵袭，得水之地最好、藏风次之。
- 罗盘（罗经仪）：风水探测工具，中央磁针加同心圆圈，含八卦、干支、星宿、五行。唐代杨筠松创二十四山（周天三百六十度均分二十四等份，每山十五度，三山一卦）。
- 煞：风水不利因素统称，分形煞（反弓煞、天斩杀等）、味煞、光煞、声煞、理煞（如二十四山劫煞）。
- 二十四山：地支八干四维组成的坐向系统，每山十五度，是罗盘主要层次之一。
- 三元九运：一百八十年一大周期，分上中下三元各六十甲子，每元三运每运二十年。2024 年进入下元九紫运。
- 玄空九星：一白贪狼、二黑巨门、三碧禄存、四绿文曲、五黄廉贞、六白武曲、七赤破军、八白左辅、九紫右弼。一四六八九为吉星，二三五七为凶星。
- 旺山旺向（到山到向）：山星当令星落在坐山宫、向星当令星落在向首宫，主人丁兴旺财源广进，为玄空最吉格局。
- 零正神：当运旺星为正神宜见山气口，对宫衰星为零神宜见水。「拨水入零堂」为收吉水法门。
- 城门诀：向首左右两宫与向首同元龙之山向，配水得法为财源吉水，时效限于当运。
- 五气（旺生死煞退）：当令星为旺气、未来星为生气、远处星为死气、更远为煞气、已过为退气。

## 流派与方法

- 峦头派（形势派）：杨公风水（杨筠松）为显学，核心「觅龙、察砂、观水、点穴、立向」，经典《撼龙经》《疑龙经》《葬法倒杖》。九星寻龙点穴（贪狼巨门武曲等吉，廉贞文曲禄存破军为凶）称「流星赶穴」，为寻龙上乘之法。
- 八宅派（大游年派）：代表作《阳宅三要》。以八卦坐山配游年九星论吉凶（伏位天医生气延年四吉，五鬼绝命祸害六煞四凶）；分东四宅西四宅，东四命配东四宅、西四命配西四宅。
- 三合派：含十二长生水法（长生沐浴冠带临官帝旺衰病死墓绝胎养配来去水口）、辅星翻卦法。
- 三元派（玄空风水）：清代蒋大鸿、沈竹礽等创立，玄空出自《天玉经》《青囊奥语》。分玄空飞星派（九宫飞星图排九星定吉凶）与玄空大卦派（按卦气卦运论断）。今三元派多专论玄空。
- 金锁玉关（过路阴阳）：不用罗盘，断阴阳宅四周转一圈即可断吉凶，本质属峦头形势派。
- 乾坤国宝（龙门八局）：民国初杨藏华传出，看先后天八卦方位论断吉凶。
- 命理风水：以个人命理喜忌神为准，在宅中对应位置做能量放大或抑制，针对个人起效快。
- 八卦派（摇鞭断宅）：以向飞星为上卦、大门水口为下卦配六十四卦断吉凶，属断章功夫。

## 解读范式

- 玄空飞星排盘三参数：元运（大运）、坐山与朝向（山向）、水口位置。排盘分下卦与替卦（坐向中央九度内为下卦，出此度数为替卦），得运盘、山盘、向盘综合飞星盘。
- 吉凶判断：一白事业、四绿文昌、六白权力、八白财富、九紫喜庆为吉；二黑主病、三碧主口舌、五黄主灾祸、七赤主破耗为凶。看各宫位星曜组合与生克关系。
- 旺山旺向须峦头配合：后方有秀峰高大建筑、前方有环抱河水清池或空旷地方为合局；反之上山下水主损丁破财。
- 理气须与峦头相配才应验：飞星凶煞若无峦头对应则不应验；只重形不重方位是形法缺陷，只重理不察山水形态则断事定量不准。
- 断事分工：形法断事「定量」准确（山水形状大小定吉凶程度），理法（玄空）断「岁运吉凶」变化准确；风水学的灵魂是形法、精髓是理法，以形为体以理为用。
