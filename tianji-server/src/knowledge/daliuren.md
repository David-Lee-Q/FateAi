# 大六壬 知识库

> 领域：东方命理 ｜ 系统：daliuren

## 体系概述

大六壬是中国古代术数「三式」（太乙、奇门、六壬）之一，被誉为三式之首，与奇门遁甲、太乙神数齐名。它以天干地支为基础，用占问时辰推演天地盘、四课、三传，配合十二天将、课体格局、神煞、六亲，预测具体人事的吉凶成败。大六壬以人事预测见长，善断事业、财运、婚姻、官司、出行、疾病、失物、天气等日常事务，时效性强、体系严谨。名称来源一说壬为水主智慧，一说壬位占六故称六壬。「卜人十件」强调日干、日支、三传、时辰、年命、行年、太岁、方位等皆须参考。大六壬体系庞大，但入门从三传四课入手相对容易，精通需长期钻研。

## 核心概念与术语

- 式盘（天地盘）：地盘为十二支本位（固定），天盘以月将加于占时之上转动而成。天盘之地支称「乘」，地盘之地支称「临」。
- 月将：太阳躔度所临之宫，正月亥将、二月戌将……以中气换将（如雨水换亥将），交节换将最准确。
- 四课：以日干支为基础立课，一课（日阳）、二课（日阴）、三课（辰阳）、四课（辰阴），皆以地盘+上神形式呈现。干为我、支为彼（对方事体环境）。四课中干之两课为外、支之两课为内。
- 三传：初传（发用）、中传、末传。初传为事之发端与先机，中传为事之进行（移易门），末传为事之终结（归计门）。一般三传即事情的开头经过结果。
- 九宗门：起三传的九种方法——贼克、比用、涉害（含孟仲季）、遥克、昴星、别责、伏吟、返吟、八专。原则：有上下克者依贼克比用涉害取用；无上下克取斜克（遥克）；再无则用昴星、别责、八专、伏吟、返吟法。贼（下克上）、克（上克下），先取下贼后取上克。
- 十二天将：贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后，顺序固定、以贵人开头，分顺逆排布（亥至辰顺、戌至巳逆）。
- 起贵人歌诀：甲戊庚牛羊、乙己鼠猴乡、丙丁猪鸡位、壬癸兔蛇藏、六辛逢马虎，此是贵人方。
- 课体格局：元首、重审、涉害、遥克、昴星、别责、八专、伏吟、返吟及铸印课、富贵权印课、杜传课、亨通课等特殊课体，决定整体吉凶趋势。
- 类神：相当于奇门中的用神。占财看青龙、占妇女看天后、占罪囚看太阴、占交易看六合、占火光词讼看朱雀、占斗讼淹留看勾陈、占病人看白虎、占惊恐怪异看螣蛇、占盗贼遗亡看玄武、占酒食看小吉、占衣物看太常。
- 神煞：驿马主走动、墓库主困、丧吊（丧门吊客）主丧、闭口（癸）主事闭塞等，辅助取象判断。
- 六亲：以日干为基准定子孙、兄弟、父母、官鬼、妻财（如甲日生巳火为子孙、同寅为兄弟、亥生甲为父母）。
- 遁干：地支下所遁之天干，辅助判断（如癸为闭口主事情闭塞）。
- 空亡旬空：空亡之干支力量减弱，重要神煞落空则失去作用。

## 起课方法

- 起课三步骤：①月将加占时起天地盘 → ②以占日干支起四课 → ③按九宗门起三传。
- 四课起法：看地盘上占日干支（干寄宫、支本位）之上的天盘地支立课，逐课而上：如甲子日，地盘甲（寅）上见丑为第一课，丑上见子为第二课，子上见亥为第三课，亥上见戌为第四课。
- 占时：以人动问或动念的时辰为基础，一般以当前时间起课（也可用活时）。
- 真太阳时：排盘需用真太阳时，时区差异影响月将加时与昼夜贵人判定。
- 参考本命行年：断课时尚须参考课之当事者的本命（生年地支）与行年。

## 解读范式

- 断课步骤：先看课体格局定整体吉凶 → 分析三传发展（初传起因、中传过程、末传结果）→ 看十二天将配置定性 → 看神煞组合 → 结合六亲关系 → 查空亡旬空 → 综合五行生克制化定论。
- 日辰主客：日上神为尊主外，支上神为卑主内；支克干尊长有灾、干克支卑幼有祸；上下相生内外和谐为吉。
- 三传吉凶：三传相生为吉、相克为凶、传归日干为吉；初传凶中传吉可移凶化吉（移易门）；末传藏结局玄机。
- 神将吉凶：贵人、青龙主吉，白虎、玄武主凶；吉神临吉将大吉、凶神临凶将大凶。但须按具体情况灵活看。
- 课体吉凶分类：元首、知一等为吉课；重审、涉害、伏吟、返吟为凶课；遥克、昴星、别责、八专为平课。
- 旺衰判断：五行依四时旺相休囚死；旺相为人、休囚为物；日干旺相则事由己主、休囚则力不从心。
- 无巧不成课：依课上最显明的信息断课。若课体与类神不一、信息不明显，结果往往向反面发展。
- 毕法赋格局：《六壬毕法赋》一百句（上下各五十），如「前后引从升迁吉」「旺禄临身徒妄作」「三传递生人举荐」「三传互克众人欺」「传墓入墓分憎爱」等，用于精确断事。

## 应期推断

- 应期迟速：旺相事应速，衰囚事应迟；发用木局冬属相气则旺相事应速；相待未来必待乘旺时事成。
- 依发用定应期：初传为发用，所占事之先机动机蕴于其中。
- 据所测事体定吉凶应期：以类神上传状态判断事件何时应验。
- 空亡应期：发用实而中末空为杜传课，主事中途终止；空亡以填实、出空为应。
- 马星应期：马星发用主动，冲马、马动之时为应；马遭夹克、被合（缚足）则动不了。
