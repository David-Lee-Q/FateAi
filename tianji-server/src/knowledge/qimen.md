# 奇门遁甲 知识库

> 领域：东方命理 ｜ 系统：qimen

## 体系概述

奇门遁甲是中国古代术数最高深的门类之一，与太乙、六壬并称「三式」，被誉为「帝王之学」「方术之王」。传说起源于黄帝战蚩尤时九天玄女授书，历史上姜子牙、张良、诸葛亮、刘伯温等均传为精通者。它综合天文、历法、地理、阴阳五行与八卦理论，通过排布天盘、地盘、人盘、神盘四盘，结合九宫八卦，分析时空能量流动，用于选择时机方位、预测发展趋势与制定决策。「奇」指三奇（乙丙丁），「门」指八门（开休生伤杜景死惊），「遁」指六甲遁于六仪（戊己庚辛壬癸）之下以隐藏保护。「学会奇门遁，来人不用问」——奇门强于一事一占的时机决策，尤重「因时制宜、因地制宜、因人制宜」。

## 核心概念与术语

- 三奇六仪：三奇为乙（日奇）、丙（月奇）、丁（星奇）；六仪为戊己庚辛壬癸，各遁藏一甲（甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸）。固定排列顺序为戊己庚辛壬癸丁丙乙。
- 四盘：天盘（天时，含九星与天盘干）、地盘（地利，含地盘奇仪）、人盘（八门，管人事）、神盘（八神）。
- 九宫：洛书九宫（坎一坤二震三巽四中五乾六兑七艮八离九），纵横相加皆十五。
- 八门：休、生、伤、杜、景、死、惊、开。开休生为三吉门，伤死惊为三凶门，杜景为平门。
- 九星：天蓬、天芮、天冲、天辅、天禽、天心、天柱、天任、天英，各居本位宫。辅禽心星为上吉，冲任小吉，蓬芮大凶，英柱小凶。
- 八神：值符、螣蛇、太阴、六合、白虎、玄武、九地、九天（转盘法）；飞盘法用九神（值符、螣蛇、太阴、六合、勾陈、太常、朱雀、九地、九天）。
- 值符值使：值符为当班九星（旬首所在宫对应之星），值使为当班八门。值符常遣加时干，值使顺逆遁宫去。
- 阳遁阴遁：冬至后用阳遁、顺布奇仪；夏至后用阴遁、逆布奇仪。阳遁顺仪奇逆布，阴遁逆仪奇顺行。
- 定局：每个节气分上中下三元，五日换一元，按日干支查表定局数，共阳遁九局阴遁九局十八局。
- 伏吟反吟：星门各落本位为伏吟（主停滞，应期慢）；星门落对冲宫为反吟（主动荡，应期快）。
- 门迫：门克宫为门迫（所迫之事难成），宫克门为宫制（有制而不凶）。「宫制其门不为迫，门制其宫是迫雄」。
- 入墓：三奇六仪入墓库之地（如丙火墓戌、乙木墓未、丁火墓戌），诸事不宜；时干入墓亦忌（戊戌壬辰丙戌癸未丁丑）。
- 空亡旬空：旬空之宫信息落空，以填实、冲实为应期。
- 马星（驿马）：申子辰马在寅、寅午戌马在申、巳酉丑马在亥、亥卯未马在巳，主变动。
- 六仪击刑：甲子值符加震宫（子刑卯）等六仪落刑地，大凶。
- 三奇得使、玉女守门：三奇逢六甲所使之时为吉格。
- 五不遇时：时干克日干（如甲日忌庚时），主诸事不顺。
- 三遁：天遁（生门+丙+丁）、地遁（开门+乙+己）、人遁（休门+丁+太阴），宜藏形遁迹、成就隐秘计划。
- 庚格：天盘庚加地盘年月日时干，主阻隔，用于破案、寻人、找物断应期。庚空亡入墓不为格、乙庚合不为格。

## 排盘方法

- 起局三步：①确定时间（真太阳时）并换四柱干支→②查节气定阴阳遁、按日干支定局数（上元阳遁顺排、中元、下元各有数字）→③布三奇六仪定地盘。
- 排盘顺序：定局数→排地盘干（三奇六仪按局数入九宫）→查旬首定空亡→排天盘干（旬首加时干宫，诸仪随动）→排九星（随天盘干转）→定值符值使→排八门（值使按阳顺阴逆数至时干宫）→排八神（值符顺逆依次螣蛇太阴六合白虎玄武九地九天）→排暗干（时干找值使宫报道，三奇六仪按阳顺阴逆排布）→标空亡、驿马。
- 流派：时家奇门最常用（以时辰为单位）；分转盘法（八神）与飞盘法（九神）；排法有拆补法与置闰法。年以立春为界、月以节气交接为界，跨节气易排错。
- 十八局：初制四千三百二十局，太公删为七十二局，张良精简为阴阳各九局共十八局。

## 解读范式

- 解盘七步：定用神→看用神落宫状态（空亡、马星、墓库、刑冲、生旺墓绝）→看八门吉凶与门迫→看九星旺衰→看八神吉凶→看奇仪格局（十干克应）→综合断吉凶与应期。
- 用神选取：一般事以时干为用神；人生大事结合年命；工作看开门、学业看景门、婚姻看六合、求财看生门；破案寻人找物看庚格。
- 主客关系：动则看方位上天地人神四盘；天盘生合地盘主吉、地盘生合天盘次吉、天盘克地盘招非厄、地盘克天盘有始无终。
- 旺衰判断：以月令为主看用神与各宫旺相休囚死墓绝；值符值使、时干落宫旺衰定吉凶。
- 九星属性：天蓬凶主冒险破财、天任吉主稳定、天冲主动荡、天辅吉主文运、天心吉主智慧谋略、天柱凶主口舌、天英平主虚名、天芮凶主疾病。
- 吉格凶格（十干克应）：青龙返首（甲+丙）大吉、飞鸟跌穴（丙+甲）大吉；青龙逃走（乙+辛）、白虎猖狂（辛+乙）、荧入太白（丙+庚）、太白入荧（庚+丙）、蛇夭矫（癸+丁）、雀投江（丁+癸）为凶格。
- 门星神配合：吉门合三奇百事宜；三奇得使、值符值使相会为吉；凶宿得奇门仍不宜用。

## 应期推断

- 三大原则：①以用神旺衰、长生墓绝、内盘外盘、伏吟反吟定远近快慢（远慢断年月、近快断日时；伏吟主慢、反吟主快）→②先定地支后配天干→③先以值符定应期、后以值使定应期。
- 值符定应期：值符相冲以合为应（如甲子加离九宫子午冲、子丑合应在丑）；相刑以合为应；值符落旬空以出旬填实为应。
- 天盘六仪定支：逢冲以合定地支、逢合以冲定地支；不冲不合以星门生克定（生逢生日、克逢克日）。
- 用神落宫定应：用神落坤应未申、落巽应辰巳；逢空以冲空填空为应、逢马以冲马马动为应、入墓以冲墓为应、刑冲以合为应。
- 数理取应：值使门或时干落宫数即为期限（后天八卦数坎1坤2震3巽4中5乾6兑7艮8离9），应几日几月；值使门所临之干亦为应期。
- 庚格应期：破获、寻人找物类事以庚格定应期——庚临年格应年内、月格当月、日格当日、时格当时；阴日看庚上之干、阳日看庚下之干。
- 成功类以用神旺相当令、生逢生时克逢克时、填实冲实、冲库、马星当令为应；失败类以用神休囚死墓绝、忌神旺相用神受克为应。
- 值使门控时效：值使门是事情的时限枢纽（落几宫即几月几天），好事坏事都有时限，过限即变。

## 经典文献

- 《烟波钓叟歌》：奇门遁甲总纲歌诀，涵盖源流、定局、星门神奇仪排布与吉凶格。
- 《奇门遁甲秘笈大全》（清）：系统汇辑奇门理论与应用。
- 《奇门法窍》（清锡孟樨）：专论断应期之法。
- 《太白阴经》（唐李筌）、《景佑遁甲符应经》、《遁甲演义》（明程道生）：数奇门经典。
- 《奇门一得》：主客与值符值使落宫断法。
