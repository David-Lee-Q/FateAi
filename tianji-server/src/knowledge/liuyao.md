# 六爻 知识库

> 领域：东方命理 ｜ 系统：liuyao

## 体系概述

六爻占卜是《周易》的应用分支，起源于西汉京房的「纳甲筮法」，历经两千余年发展，在明清时期成熟。它以三枚铜钱摇卦六次成卦，通过纳甲、装地支、定世应、装六亲、装六神，结合月建、日辰、动爻、变爻之间的五行生克制化关系，具体判断一件事情的吉凶成败与应验时间。与八字、紫微侧重人生大势不同，六爻专攻「一事一占」，适合决策婚姻、事业、财运、疾病、出行、官司、考试等具体问题。经典著作以野鹤老人《增删卜易》与王洪绪《卜筮正宗》为代表。核心口诀「卦不妄成，爻不虚发」——动爻必有因，是断卦的根基。

## 核心概念与术语

- 六十四卦：八宫（乾兑离震巽坎艮坤）各领八卦而成，如乾宫八卦：乾、姤、遁、否、观、剥、晋、大有。
- 世应：世爻代表求测者自身，应爻代表所测对象或对方；世应相生合主吉，相克主凶。世爻又称主象、主事爻。
- 六亲：父母、兄弟、子孙、妻财、官鬼，按各宫五行与我（宫位五行）的生克关系安配——生我为父母、我生为子孙、克我为官鬼、我克为妻财、比和为兄弟。
- 六亲拟象：父母主文书、房屋、车辆、长辈；子孙主医药、福神、下属、动物；官鬼主官职、疾病、丈夫、盗贼；妻财主钱财、妻子、货物；兄弟主朋友、竞争、破财。
- 原神、忌神、仇神：生用神者为原神，克用神者为忌神，克原神或生忌神者为仇神。用神旺相、忌神受制则吉。
- 用神：所测之事的对应爻。自占以世爻为用；占他人按六亲取用；占工作官鬼为用、占考试父母为用、占财妻财为用、占病官鬼与世爻为用。用神两现取动爻、旬空月破或临世应者。
- 伏神飞神：用神不现于卦中时，从本宫卦查伏神，伏神之上的爻为飞神；伏神得日月生、旺相、得飞神生、得动爻生、飞神受制等为「伏而易出」之有用伏神。
- 月建（月令）：掌一月之权，司三旬之令，可生克冲合卦中所有爻；爻临月建、与月五行同或相生、被月合者为旺相；被月冲为月破。
- 日辰（日建）：为六爻之主宰，司四时之旺相，四时俱旺、操生杀大权；冲旺相之静爻为暗动，冲衰弱之静爻为日破；冲空即起、冲合即开。
- 旬空（空亡）：十日为一旬，每旬两个地支落空。用神空亡事有不成之象，忌神空亡为去病之象；出旬填实为应期。
- 动爻变爻：老阳老阴为动爻，动则变化出变爻。动爻为重、静爻为轻；动爻能生克冲合他爻，变爻能回头生克冲合动爻；动化回头生、化进神为吉，化回头克、化退、化绝、化墓为凶。
- 化进化退：动爻变出同五行之爻，顺序往后为化进（如寅化卯），往前为化退（如卯化寅）。
- 六冲六合：六冲（子午、丑未、寅申、卯酉、辰戌、巳亥）主事急、散、快，吉事不宜冲；六合（子丑、寅亥、卯戌、辰酉、巳申、午未）主事缓、成、慢。
- 六神（六兽）：青龙、朱雀、勾陈、螣蛇、白虎、玄武，依占日天干排布，只作细节参考，不能决定吉凶。
- 三墓：用神入日墓、入动爻墓、动而化墓；入墓待冲墓之日应事。
- 三合局：三爻合成申子辰、亥卯未、寅午戌、巳酉丑水木火金之局，用神局吉，忌神局凶；虚一待用。

## 起卦与装卦方法

- 铜钱摇卦：备三枚铜钱（乾隆通宝为佳）或相同硬币，净手静心，一事一卦，心中默念所问之事后抛落，共摇六次，自下而上记录。两正一反为少阳（丶），两反一正为少阴（、、），三反为老阳（○），三正为老阴（×）；老阳老阴为动爻。
- 一事一卦：同一件事不可重复占问；一卦只问一事；代占须说明与求测者的关系。
- 装卦四步：①定卦宫、装地支（纳甲）→ ②装六亲（依宫位五行与地支五行生克）→ ③定世应（按各宫卦世爻位置歌诀）→ ④装六神（按占日天干，初爻起：甲乙青龙、丙丁朱雀、戊勾陈、己螣蛇、庚辛白虎、壬癸玄武）。
- 时间起卦法（梅花易数）：上卦=（年+月+日）÷8 余数，下卦=（年+月+日+时）÷8 余数，动爻=（年+月+日+时）÷6 余数。
- 数字起卦法：一组数字（3-5 位）前取上卦后取下卦再定动爻；或两组数字分别作上下卦。1乾2兑3离4震5巽6坎7艮8坤。
- 起卦禁忌：心不诚、事不专、一卦多问、求测不严肃皆影响卦象准确。

## 解读范式

- 断卦顺序：取用神 → 看旺衰（月令旺相休囚 + 日辰生扶克害）→ 察动爻（动为重静为轻）→ 观生克（动爻克静爻为重克、生静爻为重生）→ 看变卦（结果趋势）→ 综合断吉凶 → 推应期。
- 旺衰综合判断：先看月令旺相休囚，次看日辰生扶克害，再看动爻生克冲合，最后看卦中其他爻影响。
- 吉凶层次：《易隐》云「用神旺相事必成，忌神旺相事必败」。用神旺相、原神有力、忌神受制、卦无冲克为吉；用神衰弱、忌神猖狂、卦逢冲克、用神空破为凶。
- 作用层级：第一层日月建为衡量旺衰根本标尺；第二层动爻变爻为吉凶核心驱动力；第三层六神、伏神、纳音仅丰富细节，不能推翻核心判定。
- 动爻层次：一爻动事专一、以动爻为主；二爻动看两动爻关系、以上爻为主；多爻动事体繁杂、看用神与世应关系。
- 应期口诀：「动待合，静待冲；衰待旺，旺待墓；冲待合，合待冲；空待出，墓待破；伏待引，吟待冲。」「用旺还须墓日定，用休生旺日当成。用伏但看用值日，动逢合住待冲神。」
- 应期分类：值日填实、冲合应期（静逢值逢冲、动逢合逢值）、生旺墓绝应期、三合局应期、远近应期（远断年月、近断日时）。
- 卦意分析：用忌互化（用神化忌神、忌神化用神、用神仇神互化）为凶兆；代入确认法把世应及相关爻代入人事逐一对应分析。

## 分类占断要诀

- 婚姻感情：男占妻财为用、女占官鬼为用；世应相生合主感情好，相克主不合；子孙动克官鬼不利女占，兄弟动克妻财不利男占。
- 事业工作：官鬼为用神主职位，父母旺相主有单位文书，妻财旺相主待遇好，子孙动克官鬼不利工作。
- 财运投资：妻财为用神、子孙为财源、兄弟为破财；妻财旺相、子孙动而生之则财运亨通。
- 疾病健康：官鬼为病、世爻为自身；官鬼克世病重、官鬼受制病将愈；子孙爻为医药，子孙动克官鬼主愈。
- 考试升学：父母为成绩文书、官鬼为名次；父母旺相、官鬼有气主中。
- 官司词讼：官鬼父母世应结构断胜负与和解空间；喜庆事不宜冲、官讼忧愁事宜冲散。

## 经典文献

- 《增删卜易》（野鹤老人）：六爻断卦第一经典，重实证、删繁就简，「神兆机于动」。
- 《卜筮正宗》（王洪绪）：完善用神、原神、忌神体系与日辰理论，「日辰为六爻之主宰」。
- 《卜筮全书》《黄金策》《易隐》《易冒》：六爻理论体系的重要补充。
- 《京房易传》：纳甲筮法源头。
