# 铁板神数 知识库

> 领域：东方命理 ｜ 系统：tieban

## 体系概述

铁板神数又称铁版神数、铁板算命、铁版神算，俗称铁算盘，是中国古代命理术数之一。托名北宋邵雍（邵康节）所创，但史书无证；据传满清中叶道长铁卜子（铁道人）以该术为人算命，以「斩钉截铁式翻阅条文」的方式将命书交与求测者，一时盛行，故称「铁版」（铁卜子版本）。现存主流版本多源自清代道光年间刻印的《神机妙算铁版数》（收入《续修四库全书》子部），其条文与明代宫廷御用的《皇极分经数》高度相似，后者被视为流行的一万二千条文版本（岭南派）的始祖。它并非独立术数，而是融汇易卦、河图洛书纳甲、子平八字、紫微斗数、七政四余等多体系知识的综合性术数。其核心特色是「考时定刻」与条文论断，将生辰八字经数字运算映射到约一万二千条固定条文，推演人生具体事件，尤以六亲生肖测算灵验著称。

## 核心概念与术语

- 条文：铁板神数的最终论断载体，约一万二千条，按宫位、五行、天干组织分类，每条数句四言/七言断语。
- 考时定刻（考刻定分）：因求测者提供的时间只是大概，需将出生时间推至一时辰八刻、一刻十五分的精细度。术者打出条文问求测者是否正确，循环验证校准命盘，再推其余条文。南派重日干支与时干支推算（传至香港），北派重月柱与时辰干支（近代几乎失传）。
- 起基本命数：将生辰化为核心数字，口诀「时上起元，遁千十百里」。入门公式如（时支序数×30 + 日干序数 + 调整数）÷5 = 太玄基数。
- 元堂卦：将基本命数÷6取余数定动爻，得一生「主题卦」，动爻所在决定人生主要关注点与变化枢机。
- 秘数：将基础命数导向不同人生领域（父母、妻财、流年等）的加减常数，最终条文号 = 基础命数 ± 秘数。
- 乾系与坤系：条文分两大类。乾系偏公开可讲，坤系为密文（指向婚变、疾病、官司等重大事件），需专门流年表、流度表辅助解码。
- 宫位分类：乾宫主事业、坤宫主母族根基、震宫主动变、巽宫主金钱人际、坎宫主疾病关卡、离宫主学业官司、艮宫主停滞节点、兑宫主喜庆口舌。
- 甲表乙表丙表：条文细分索引，甲表主事业、乙表主财富人际、丙表主家庭亲情。
- 八卦滚法：以基本卦逐爻取互卦变卦共得八卦，每卦按数序组合求得三十六至四十八条条文。

## 起数与排盘方法

- 正统演算五步骤：①求人数（演算时年月日时）→ ②求天数（生辰年月日时）→ ③以天数和人数求六亲年命纳音五行与年支（起紫微命盘求八宫正数、起河洛先后天命卦与流年卦配六亲、求十干变曜配二十八星宿、起大定数）→ ④求地数（以六亲数演）→ ⑤求铁板数序。
- 皇极起数流程：八字排盘 → 起基本命数 → 起元堂卦 → 考刻定分 → 条文演算 → 查阅条文。
- 天干配卦诀：壬甲从干数、癸乙向坤求、庚来震上立、辛在巽方留、己以离门起、戊以坎为头、丙须艮处出、丁向兑家收。
- 地支配卦诀：亥子坎宫寅卯震、巳午离门未在坤、申酉兑金干是戌、丑入艮宫辰巽真。
- 太玄配数诀：甲己子午九、乙庚丑未八、丙辛寅申七、丁壬卯酉六、戊癸辰戌五、巳亥单四数。
- 八卦加则例：爻从三十起、乾卦六为头、变知六八止、应世两同俦。
- 大运取数诀：月日时年、春夏秋冬、亥子一六、干支合数。值年卦诀：欲知流年事，还看年干支。
- 条文检索：先按宫位（钳工甲流度）→ 再按五行（木火土金水宫）→ 再按天干（甲乙丙三类），类似三层图书索引定位条文段落。

## 解读范式

- 考时定刻为先：所有条文推算以校准后的精确时刻为基，调整数是「唯一密钥」，推不出与已知六亲信息吻合的条文则需重调。
- 条文分类解读：条文按内容分为父母出身、兄弟姐妹、婚姻夫妻、子女、性格、事业财运、流年运程、师友、健康、其他共十类。
- 先后天卦相合：先天卦象征结构与天性，后天卦象征环境与职业，两卦相合才能查阅条文；先后天加折法判断身体系统，动爻象急症、变爻象慢症。
- 大运流年卦：大运取数法将十年大运转换为「大运主卦」；流年法将年份加大运卦主卦时刻数形成年度事件模板。
- 元会运势：判断时代背景，解释为何同命之人在不同时代走出完全不同的轨迹。
- 应用边界：铁板神数以先天之数推六亲最为灵验，推断财运和流年准确度偏弱（后天之运含人为改造与趋避），是为其最大局限。

## 经典文献

- 《皇极经世》（邵雍）：皇极起数的思想源头，元会运世宇宙观。
- 《皇极分经数》（明代宫廷）：一万二千条文岭南版之始祖。
- 《神机妙算铁版数》（清道光刻印本）：现流行条文主要来源，收入《续修四库全书》。
- 《铁版数不分卷》（旧钞本）：四库书目所载另一部铁版数文献。
- 《皇极经世神数》（邵夫子神数）：传女南派 12000 条；传子北派精简算法与条文。
