# 月相 知识库

> 领域：西式占卜 ｜ 系统：moonphase

## 体系概述

月相是地球上所观看的月亮形态：月球本身不发光，只反射太阳光，地球、月球、太阳相对位置规律变化使观测者看到月球被照明的部分不断盈亏圆缺。月相盈亏周期（朔望月）平均 29.53 日。传统公认八个月相：四个主要月相（新月、满月、上弦月、下弦月）与四个次要月相（蛾眉月、盈凸月、亏凸月、残月）。在占星与民俗中，月相被用于安排生活节奏——新月是启动新计划的起点，盈月期（上弦至满月）适合扩张推进，满月是成果展现与情绪高点，亏月期（下弦至新月）适合收敛、释放与清理。日蚀与月蚀则是加强版的新月与满月。

## 核心概念与术语

- 朔望月：从新月到新月的周期，约 29.5 天，是历法上的朔望月。
- 月龄：距上次新月过去的天数，描述月亮在周期中的位置。
- 新月（朔，黄经差 0°）：月球位于地球与太阳之间，面向地球一侧未被照亮，几乎不可见。象征新起点、许愿、启动计划。
- 蛾眉月（Waxing Crescent，+45°）：新月后月盘一小部分可见，盈月期开始。
- 上弦月（+90°）：月球完成轨道四分之一，月盘一半被照亮（北半球亮右半）。属于盈月期，适合行动与扩张。
- 盈凸月（Waxing Gibbous，+135°）：一半以上照亮、逐渐增长，能量持续累积。
- 满月（望，180°）：地球位于月球与太阳之间，整个月面被照亮，最明亮显眼。象征成果展现、情绪高峰、答谢收获；民间认为此时人易激动，不宜做重大决策。
- 亏凸月（Waning Gibbous，-135°）：满月后照亮部分减少，进入收敛期。
- 下弦月（-90°）：月盘一半被照亮（北半球亮左半），亏月期，适合收尾、清理、释放。
- 残月（Waning Crescent，-45°）：新月之前仅一小部分可见，继续缩小至新月。
- 农历对应：初一朔（新月）、初七/初八上弦、十五望（满月）、廿二/廿三下弦，月相与农历日期基本对应。
- 日月蚀：太阳与月亮在南北交点（18.5 度内）合相对冲时发生，日蚀=加强版新月，月蚀=加强版满月，常是危机也是转机。

## 排盘与推算方法

- 月相由月球黄经与太阳黄经之差决定：朔=0°、蛾眉月=+45°、上弦=+90°、盈凸月=+135°、望=180°、亏凸月=-135°、下弦=-90°、残月=-45°。
- 推算工具：按用户出生/询问日期查月相历（moon calendar）或农历，得出当日月相与所落星座/宫位。
- 个人应用：观察新月落在自己本命盘的哪个宫位，代表该领域会有新开始；满月发生的宫位，表示该放掉哪些习性；前后两周是事件可能触发的时间。
- 日月蚀与行运：看日月蚀是否与本命盘主要行星成相位；北交点日蚀主正向转变，南交点日蚀主验收与清算。

## 解读范式

- 新月（启动期）：适合设定目标、许愿、开展新计划、开始新关系；不宜急于求成，宜播种。
- 上弦月（行动期）：盈月期动力上升，适合推进、扩张、谈判、积极行动。
- 满月（成果期）：成果显现、情绪与能量达峰值；适合庆祝收获、看见结果；也是释放与放下的契机。民间提示满月前后情绪易起伏，避免冲动决策。
- 下弦月（收敛期）：亏月期能量下降，适合清理、结束、放下、复盘、节省精力。
- 残月（沉淀期）：能量最低，适合内省、休息、排毒、做减法。
- 情绪与身体：月相引力影响潮汐，人体约 70% 为水，故新月/满月前后情绪敏感，适合标记日历提前注意。
- 日蚀月蚀（转折期）：日月蚀常带来人生方向大转弯、突发变化或长期事件的结果；日蚀图指向个人年度发展方向重点，月蚀图偏向关系转变。
- 各月满月名称：1 月狼月、2 月雪月、3 月虫月、4 月粉月、5 月花月、6 月草莓月、7 月鹿角月、8 月鲟鱼月、9 月丰收月、10 月猎人月、11 月海狸月、12 月寒月，用于标记季节与农事。

## 经典文献

- 《月亮的智慧》及月相占星类作品：月相与个人成长应用。
- 占星推运文献：新月/满月/日月蚀落宫落座的流年解读。
- 天文学文献：月相周期与黄经计算（朔望月定义）。
