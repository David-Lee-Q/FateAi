# 手相 知识库

> 领域：东方命理 ｜ 系统：palm

## 体系概述

手相（掌相）是通过观察手掌掌纹、掌丘、手形与色泽来判断性格、健康与运程的占卜术，有「万相之首」之称，融合了千年文化与经验案例总结。手相主要观察五条主线：生命线、智慧线（脑线/人纹）、感情线（天纹）、事业线（命运线/玉柱线）、婚姻线（姻缘线），辅以太阳线、健康线、财富纹、人缘线、神秘十字纹等次要纹路，并结合金星丘、月丘、木星丘、土星丘等掌丘与五行手形综合解读。关于左右手：「男左女右」是误解，通行说法为「左手先天、右手后天」——右手代表后天现状与意识层面的生活，左手代表先天性格与潜意识；判断以惯用手为主、非惯用手为辅（一说右手占八成、左手两成）。手相会随心境与经历改变，「相由心生」，手相解读宜作自我觉察参考而非宿命定论。

## 核心概念与术语

- 生命线（地纹）：从拇指与食指间虎口向掌底延伸。长短不代表寿命，代表生命力强弱、体力精神、健康疾厄与家庭环境运气。长深红润生命力强；浅弱体虚；链状主儿时体弱；尾端流苏防老人病；岛纹主某时段生病住院。
- 智慧线（人纹）：起点与生命线同，向小指方向延伸，是五大主线中最重要者，代表思考力与智力。至无名指与无名指下小指间为佳；深细为佳（思想集中）；过长精明过度易以自我为中心；过短反应迟缓；岛纹主思想不集中。
- 感情线（天纹/父纹）：小指下掌边向食指方向延伸，代表感情强弱、爱情观与人际关系。走入食指与中指缝为中庸；至食指下重精神之爱、入中指下重肉体之爱；深细感情细腻、粗浅感情粗放；链状多愁善感；岛纹主感情困扰；断裂主感情挫折。
- 事业线（命运线/玉柱线）：从掌底向中指根延伸，唯一垂直主线，代表事业、社交与人生运程（非人人都有）。清晰笔直主事业安定顺利；断续歪斜主工作不稳；起于智慧线主晚年以智慧成功；与感情线同起主艰苦奋斗晚年有成；有两条事业线可发展副业。
- 婚姻线（姻缘线）：小指下掌边、感情线上方的短横线。条数不主结婚次数，以最长最深一条为准；尾部上翘主缺乏结婚意愿，尾部下弯分岔主分手，岛纹主分居；过长主择偶条件高。
- 太阳线（成功线）：无名指下与事业线平行的直纹，主声名与成功；成双线称名望纹。
- 健康纹：小指下向生命线延伸之纹，其实无健康纹者才健康；断续主肠胃问题，链状主呼吸系统问题。
- 掌丘：拇指下金星丘（精力爱欲）、小指下月丘（想象力人缘）、食指下木星丘（领导野心）、中指下土星丘（沉稳压力）等。
- 断掌：感情线与智慧线合而为一，主个性鲜明、聪明、主观强，配事业线则财运事业佳。
- 五行手形：大地型（踏实负责执行）、火型（外向热情冲动）、空气型（善社交爱动脑）、水型（敏锐内向情绪化）。
- 特殊纹：财富纹（拇指节处方格/菱形交叉纹）、人缘线、不测纹、努力线/希望纹、神秘十字纹、叛逆纹、子女线等。
- 男左女右/左手先天右手后天：「男左女右」为陈旧观念；以惯用手（后天/意识/现状）为主、非惯用手（先天/潜意识/性格）为辅。

## 看相与解读方法

- 定主手：先看惯用手（右手为主、左手为辅，一说右手占八成影响力），左右对比看先天与后天的差异与调整趋势。
- 认五线：依次观察生命线、智慧线、感情线、事业线、婚姻线的位置、长短、深浅、断续与特殊纹（岛纹、链纹、流苏、分叉、十字、星纹）。
- 看质地与丘：结合手掌厚薄软硬、色泽与掌丘饱满度（厚实红润、掌丘饱满为佳）。
- 看手形定气质：先按五行手形判断人格底色，再以纹路细化。
- 综合判读：各线不能孤立解读，须与手形、掌丘及其他线纹合并分析（如生命线弱、事业线可弥补精力；婚姻走向要结合感情线、智慧线、生命线）。
- 动态看待：手相随心境与生活改变，解读宜用于自我觉察与趋吉避凶，不宜当作宿命断言。

## 解读范式

- 智慧线与生命线起点关系：起点重迭一段后分开=谨慎内向；重迭长段后分开=犹豫多虑；仅起点重迭即分开=果断应变强；起点分离=外向大胆能自立；分离超半公分=莽撞。
- 事业线起点看阶段：起点近生命线=早年依赖家庭；起自智慧线=晚年以智慧经验成功；起自感情线=艰苦奋斗晚年有成；起自月丘=人缘好得贵人助。
- 财运观纹：手掌厚实柔软、手指修长无缝隙、食指下有井字纹、四主线成 M 字纹、财富纹（方格/菱形）者主财运佳；财富纹越密集越利积累。
- 感情观线：链状多愁善感、岛纹感情困扰、断裂感情受挫；婚姻线尾分叉主分手、岛纹主分居、上翘主无结婚意愿。
- 健康观线：生命线深浅断续看体力与病厄；健康纹、太阳线、各线岛纹与病理对应（链状呼吸弱、岛纹乳腺/泌尿、生命线流苏老人病）。
- 好命手相示例：断掌+事业线（财库厚、大权在握）、事业线起于太阴丘（贵人提拔）、掌厚圆润无青筋（福气）。
- 常见误区澄清：婚姻线条数≠结婚次数与子女数；生命线长短≠寿命；手相无科学定论，解读应结合现实、积极引导。

## 经典文献

- 传统手相学（天纹/地纹/人纹体系）：中国手相以五行八卦分野判纹的古典体系。
- 西洋手相学（五大主线体系）：现代通行手相解读框架。
- 《麻衣相法》等相关相学典籍：手相与面相综合论命传统。
